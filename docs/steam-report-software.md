## Ⅱ. 주요 활동 내용

### [활동 3] LiDAR 기반 자율주행 모델 개발 및 검증

#### 활동 목표

소형 차동 구동 로봇이 2D LiDAR로 주변을 관측하고, 실내 정적 장애물을 피한 뒤 지정된 방향으로 주행을 이어가도록 자율주행 모델을 개발한다. Unity에서 학습용 주행 데이터를 만들고, 훈련에 쓰지 않은 코스에서 모델의 회피와 복귀를 확인한다.

#### 활동 내용

**1. 다양한 실내 환경을 만드는 Unity 데이터 생성 알고리즘**

특정 평면이나 장애물 배치에 치우치지 않도록, 실내 구조를 종류별로 만들고 각 구조 안에서 세부 조건을 무작위로 바꾸는 생성 알고리즘을 구현하였다. 복도망은 방을 node, 통로를 edge로 하는 graph로 구성하고, 인접한 곳부터 이어 전체 공간을 연결한 뒤 분기와 순환로를 추가하였다. 좁은 방, 여러 출입구가 있는 홀, 칸막이가 있는 홀, 어긋난 통로로 연결된 두 방도 생성하였다. random seed를 바꾸면 통로의 폭, 출입구의 수와 위치, 상자의 크기와 위치, 로봇의 출발 위치와 방향이 달라지며, 같은 seed로는 같은 조건을 재현할 수 있도록 하였다.

장애물 후보를 배치한 뒤, 상자가 빈 공간에서의 기준 경로를 실제로 가로막고 차체가 지나갈 여유가 있는 우회 경로도 존재하는지 검사하였다. 넓은 공간에서는 상자를 여러 곳에 흩어 놓고 기준 경로가 두 곳 이상 막히는 배치를 채택하여 연속 회피 상황을 만들었다. 초기 수집에서는 장애물 유무에 따른 주행 차이를 비교할 수 있도록 출발 자세와 지시가 같은 두 주행을 짝지었다.

교사 프로그램은 벽과 상자 위치를 바탕으로 A*로 경로를 탐색하고 좌우 모터를 제어하여 주행하였다. 가상 LiDAR는 0.1초마다 1° 간격으로 raycast를 수행해 거리값 360개를 얻으며, 거리 측정에 noise와 beam dropout을 적용하였다. 방향 입력 실험에서는 매 스캔의 거리값, 차량 기준 진행 방향, 좌우 모터 명령을 CSV로 저장하였다. 차량 위치와 방향, 충돌 횟수는 주행 궤적과 접촉 여부를 확인하는 데 사용하였다.

**2. Imitation learning을 이용한 모델 학습**

PyTorch로 최근 LiDAR 스캔 4개와 차량 기준 진행 방향을 입력받아 좌우 모터 명령을 출력하는 1D CNN을 구현하였다. 진행 방향은 장애물 배치와 독립적으로 제공하였으며, 모델은 교사가 기록한 좌우 모터 명령을 예측하도록 학습하였다. 교사의 우회 경로와 장애물 좌표는 교사 주행을 만드는 데 사용하였다. 동일한 맵에서 나온 기록이 훈련과 검증에 섞이지 않도록 seed 단위로 나누고, 최종 모델은 15 epochs 학습한 뒤 Unity에서 실행할 수 있도록 가중치를 변환하였다.

**3. Unity closed-loop 자율주행 평가**

Unity에서 모델이 새 LiDAR 스캔을 받을 때마다 좌우 모터 명령을 계산해 차량에 적용하도록 하였다. 차량이 움직이면 바뀐 위치에서 다시 스캔해 다음 명령을 계산하였다. 동일한 출발 자세와 진행 방향에서 장애물을 좌우로 뒤집은 코스를 만들고, LiDAR를 사용하는 모델과 LiDAR 거리값을 상수로 고정한 대조 모델의 완주와 충돌을 비교하였다. 독립 상자, 연속 상자, 복도에서 홀로 이어지는 코스, 빈 공간에서도 주행을 평가하였다.

#### 활동 결과

- **다양한 실내 구조와 주행 데이터 생성**　20개 seed로 복도망 15개, 좁은 방 평면 5개, 넓은 공간 4종 각 30개를 생성해 총 **140개 평면**의 구조와 계획 경로를 점검하였다. 별도로 3개 seed의 Unity 교사 주행을 통해 장애물 우회와 대응하는 빈 공간 주행 **37쌍**, 완전 차단 앞 정지 **3건**을 수집하였다. 저장한 LiDAR 스캔 **28,675개**에서 기록 간격 이상과 주행 중 접촉은 없었다.
- **좌우 회피 검증**　한쪽으로만 통과할 수 있는 장애물 코스 20건에서 LiDAR 모델은 모두 완주하였고, LiDAR 입력을 상수로 고정한 대조 모델은 모두 충돌하였다. 시작 자세와 진행 방향을 고정한 상태에서 첫 LiDAR 스캔을 좌우 배치에 맞게 바꾸자, 10쌍 모두에서 초기 조향 방향이 통과 가능한 쪽으로 바뀌었다.
- **연속 회피 개선**　첫 상자를 피한 뒤 차량이 옆으로 벗어나거나 방향이 크게 틀어진 자세를 모델의 주행 기록에서 골랐다. 해당 자세에서 교사를 다시 출발시켜 다음 장애물을 피하고 주행을 이어가는 데이터를 추가하였다. 같은 35개 평가 코스에서 완주는 **26건에서 35건**으로 늘었고, 연속 상자 코스 완주는 **3/10에서 10/10**으로 늘었다. 별도 seed의 연속 상자 코스에서는 **9/10**을 완주하였다.

## Ⅲ. 운영 결과

### 1. 해결하고자 한 실생활 문제들

◦ **실내 이동 지원 로봇의 장애물 회피**

- 교통약자의 물품 운반을 돕고 재난 현장에서 이동을 지원하는 로봇이 실내 통로의 장애물을 피해 주행할 수 있도록, 2D LiDAR 기반 자율주행 모델을 개발하였다.
- Unity에서 복도 중앙의 상자, 좌우로 엇갈린 여러 상자, 복도에서 홀로 이어지는 입구를 구성하였다. 모델이 장애물을 피한 뒤 지정된 방향으로 주행을 이어가 출구까지 도달하는지 확인하였다.

### 2. 교과 융합을 통해 문제를 과학적·기술적으로 해결한 내용

◦ **수학·물리**　좌표 변환을 이용해 진행 방향을 차량 기준의 두 성분으로 표현하였다. 거리와 각도, 차체가 통과하는 데 필요한 여유를 계산해 교사 경로를 만들고, 좌우 바퀴 속도 차이에 따라 차량이 방향을 바꾸도록 구현하였다.

◦ **정보·공학**　센서 관측과 모터 명령을 짝지어 1D CNN을 학습시키고 Unity 차량에 연결하였다. 출발 자세와 지시를 고정하고 장애물의 위치 또는 LiDAR 입력만 바꾸는 대조 실험을 설계하여, 센서 입력이 조향에 미치는 영향을 확인하였다.

### 3. 활동하면서 어려웠던 점 및 해결 방법

◦ **기록에서의 예측 오차와 실제 주행 결과가 달랐음**　초기 모델은 직전 교사 명령이 주어진 기록에서는 오차가 작았으나, Unity에서 자신의 명령을 다시 입력받자 조향이 불안정해졌다. 직전 명령을 입력에서 빼고 동일한 복도 코스에서 비교한 결과, 도달이 1/18에서 9/18로 늘었다. 이후에는 모델이 직접 차량을 움직이는 시험으로 성능을 확인하였다.

◦ **첫 장애물을 피한 뒤 진행 방향을 잃는 사례가 있었음**　차량의 위치와 방향을 주행 기록에서 확인하고, 정상 교사 자세와 실제 모델이 벗어난 자세를 비슷한 전후 위치에서 짝지었다. 두 자세에서 교사를 각각 재출발시키고 같은 수의 주행을 학습에 추가해 비교하였다. 기존 코스와 별도 seed의 연속 상자 시험 총 20건에서 정상 자세를 추가한 모델은 15건, 모델이 벗어난 자세를 추가한 모델은 19건을 완주하였다.
